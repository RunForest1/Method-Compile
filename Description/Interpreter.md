# 1. Архитектура данных

Интерпретатор оперирует тремя основными сущностями:

1. **Стек (`stack`)**: Хранит временные значения (`Value`) для выполнения операций.
2. **Память (`memory`)**: `std::map`, где ключом является имя переменной или вычисленный адрес массива, а значением — объект `Value`.
3. **Указатель команд (`ip`)**: Индекс текущей выполняемой лексемы в векторе ОПЗ.

## Типы данных (`ValueType`)

- `INT` (long long)
- `FLOAT` (double)
- `STRING` (std::string)
- `ADDRESS` (специальный тип для идентификаторов переменных)

---

# 2. Математическое ядро

Особенностью интерпретатора является **ручная реализация трансцендентных функций** через ряды Тейлора. Это избавляет от жесткой зависимости от стандартной библиотеки `cmath` и позволяет контролировать точность.

- **Экспонента**: Вычисляется через ряд $ e^x = \sum_{n=0}^{\infty} \frac{x^n}{n!} $.
- **Тригонометрия**: `sin(x)` и `cos(x)` используют разложение в ряд с предварительным приведением угла к диапазону $[-π, π]$.
- **Логарифм**: Реализован через итерационный метод для $ \ln(x) $.
- **Тангенс / Котангенс**: Вычисляются через отношение `sin/cos` и `cos/sin` соответственно.

# 3. Система команд (Операторы)

## 3.1. Арифметические операции

Поддерживают автоматическое приведение типов. Если один из операндов — `FLOAT`, результат будет `FLOAT`.

- `+`, `-`, `*`, `/` — бинарные операции.
- `NEG` — унарный минус (инверсия знака).
- `POW` — возведение в степень (реализовано как $ a^b = \exp(b \cdot \ln(a)) $).

## 3.2. Работа с памятью

- `:=` (Присваивание): Извлекает значение и адрес, сохраняет значение в `memory`.
- `READ`: Ожидает ввод пользователя и сохраняет его по адресу.
- `WRITE`: Выводит значение (или результат выражения) в консоль.

## 3.3. Управление потоком (Jumps)

Интерпретатор поддерживает безусловные и условные переходы, что позволяет реализовывать циклы (`while`) и ветвления (`if`).

- `J`: Извлекает адрес метки и устанавливает `ip` на неё.
- `JF` (Jump if False): Извлекает адрес метки и логическое значение. Если значение `false`, переходит по адресу.

---

# 4. Работа с массивами

Интерпретатор использует строковую модель адресации для массивов. Вместо выделения блоков памяти, адреса генерируются динамически.

| Оператор   | Формат на стеке             | Результирующий ключ в памяти     |
|------------|-----------------------------|----------------------------------|
| `INDEX1`   | `[ArrayName, Index]`        | `ArrayName[Index]`               |
| `INDEX2`   | `[ArrayName, Idx1, Idx2]`   | `ArrayName[Idx1, Idx2]`          |

---

# 5. Основной цикл выполнения (`run`)

Метод `run()` последовательно проходит по вектору ОПС:

1. Если встречает **константу** (число, строку) — кладёт её на стек.
2. Если встречает **адрес** (имя переменной) — кладёт его на стек как тип `ADDRESS`.
3. Если встречает **метку** — кладёт индекс команды на стек.
4. Если встречает **оператор** — вызывает `executeOperator`, который извлекает нужные операнды и выполняет действие.

---

# 6. Обработка ошибок

Интерпретатор выбрасывает исключения `std::runtime_error` в следующих случаях:

- Деление на ноль.
- Логарифм или степень от отрицательного числа (в определенных случаях).
- Извлечение из пустого стека (`Stack underflow`).
- Тангенс или котангенс в точках разрыва (деление на ноль при `cos` или `sin` равном 0).
