## Техническое описание интерпретатора ОПC

### 1. Основной функционал

Интерпретатор поддерживает следующие возможности:

- Работа с типами данных: целые числа (INT), вещественные числа (FLOAT), строки (STRING) и логические значения (BOOL).  

- Арифметика и логика: поддержка операций +, -, *, /, а также всех операторов сравнения.  

- Управление памятью: динамическое выделение памяти под одномерные (m1) и двумерные (m2) массивы.  

- Управляющие конструкции: реализация условий и циклов через безусловные (j) и условные (jf) переходы по меткам.  

- Ввод-вывод: интерактивное чтение данных с клавиатуры (r) и вывод результатов в консоль (w).  

- Математические функции: встроенная поддержка sqrt, exp и log.

### 2. Архитектура и структура данных

В основе системы лежат несколько ключевых структур:

- Value: Универсальное хранилище данных, использующее enum DataType для отслеживания текущего типа значения.  

- ArrayPassport: Описатель массива, содержащий его размерность (1D/2D), размеры сторон и вектор значений Value.  

- StackItem: Элемент вычислительного магазина, который может хранить либо само значение, либо ссылку на переменную/элемент массива.  

- Таблицы символов:

    - variables: std::map для хранения простых переменных.  

    - arrays: std::map для хранения паспортов массивов.

### 3. Механизм работы (Алгоритм выполнения)

Центральным узлом является метод Interpreter::execute, работающий по следующему алгоритму:

1) Инициализация: Указатель команд (ip) устанавливается в начало вектора ОПС.  

2) Цикл выборки: Пока ip меньше размера вектора, извлекается текущий RPNItem.  

3) Диспетчеризация (Switch):

    - Литералы/Переменные: Помещаются в стек как значения или ссылки.  

    - Операторы: Из стека извлекаются операнды, выполняется действие (например, evaluateMath), и результат возвращается в стек.  

    - Переходы: Изменяют значение ip на адрес метки, извлеченной из стека.  

    - Ввод/Вывод: READ приостанавливает выполнение для ожидания std::cin, WRITE отправляет данные в std::cout.  

4) Приведение типов: При выполнении операций над разными числовыми типами автоматически вызывается castToCommon, приводящий данные к FLOAT для сохранения точности.

### 4. Обработка ошибок и диагностика

Интерпретатор реализует строгую проверку во время выполнения:

- Координаты: Каждая ошибка сопровождается номером строки и символа, которые были переданы из лексического анализатора.  

- Runtime-проверки:

    - Деление на ноль.  

    - Извлечение корня или логарифма из недопустимых чисел.  

    - Выход за границы массива (как 1D, так и 2D).  

    - Попытка работы с неинициализированными массивами.

### 5. Пример работы с массивами

При обращении к 2D массиву интерпретатор использует формулу отображения в линейное пространство:

$$index = row \times dim2 + column$$

Это позволяет эффективно управлять памятью, храня данные в одномерном векторе std::vector<Value> внутри паспорта массива.
