## 1. Лексический анализ

### 1.1. Список лексем
Лексический анализатор преобразует текст программы в последовательность кодов лексем. 

| Номер лексемы | Класс лексемы | Примеры / Из чего состоит | Имя в коде |
| :--- | :--- | :--- | :--- |
| 1 | Имена (идентификаторы) | `a`, `myVar`, `array1` | `L_ID` |
| 2 | Служебные слова | `if`, `then`, `else`, `while`, `do`, `read`, `write`, `int`, `float` | `L_KEYWORD` |
| 3 | Целые числа | Последовательность цифр без знака | `L_INT` |
| 4 | Вещественные числа | Числа с десятичной точкой (например, `3.14`) | `L_FLOAT` |
| 5 | Символьные строки | Текст в одиночных кавычках `'...'` | `L_STRING` |
| 6 | Операции типа СЛОЖЕНИЯ | `+`, `-` (низший приоритет) | `L_ADDITIVE_OPERATOR` |
| 7 | Операции типа УМНОЖЕНИЯ | `*`, `/` (высший приоритет) | `L_MULTIPLICATIVE_OPERATOR` |
| 8 | Операции сравнения | `<`, `>`, `==`, `<=`, `>=`, `!=` | `L_COMPARISON_OPERATOR` |
| 9 | Оператор присваивания | `:=` | `L_ASSIGNMENT_OPERATOR` |
| 10 | Разделители | `(`, `)`, `[`, `]`, `;`, `,` | `L_DELIMITER` |
| 11 | Концевой ограничитель | `⊥` (конец файла) | `L_TERMINATOR` |
| 12 | Ошибка | Недопустимый символ или формат | `L_ERROR` |

### 1.2. Таблица переходов конечного автомата
Для распознавания лексем используется детерминированный конечный автомат. Состояния разделены на промежуточные (накопление символов), подготовительные (обработка составных знаков) и заключительные (фиксация лексемы).

**Список состояний:**
* **S_START** — поиск начала лексемы (пропуск пробелов и переходов строк).
* **S_ID** — накопление букв и цифр для идентификаторов и ключевых слов.
* **S_INT** — накопление цифр для целого числа.
* **S_FLOAT** — накопление цифр дробной части после точки.
* **S_STRING** — накопление символов внутри одиночных кавычек.
* **S_COLON** — состояние после `:`, ожидание `=` для формирования `:=`.
* **S_NOT** — состояние после `!`, ожидание `=` для формирования `!=` (одиночный `!` недопустим).
* **S_COMPARISON_OPERATOR (S_COMP_OP)** — обработка знаков `<`, `>`, `==` для формирования операций сравнения.
* **S_SLASH** — состояние после `/`, проверка на начало комментария или деление.
* **S_COMMENT_BODY (S_COM_B)** — состояние внутри блока `/* ... */` (символы игнорируются).
* **S_COMMENT_END (S_COM_E)** — ожидание `/` после `*` для выхода из комментария.
* **S_FINAL (S_F)** — заключительное состояние: лексема выделена, указатель перемещается вперед.
* **S_FINAL_BACK (S_F_B)** — заключительное состояние: лексема выделена, указатель возвращается назад.

### 1.3. Кодирование входных символов
Для реализации табличного автомата каждый символ классифицируется по категориям, соответствующим столбцам таблицы переходов.

| Категория символа | Примеры | Имя колонки в коде |
| :--- | :--- | :--- |
| Буквы | `a-z`, `A-Z` | `C_LETTER` |
| Цифры | `0-9` | `C_DIGIT` |
| Точка | `.` | `C_DOT` |
| Одиночная кавычка | `'` | `C_QUOTE` |
| Двоеточие | `:` | `C_COLON` |
| Восклицательный знак | `!` | `C_NOT` |
| Равно | `=` | `C_EQUAL` |
| Знаки сравнения | `<`, `>` | `C_COMPARE` |
| Слэш | `/` | `C_SLASH` |
| Звездочка | `*` | `C_ASTERISK` |
| Знаки сложения | `+`, `-` | `C_ADDITIVE` |
| Разделители | `(`, `)`, `[`, `]`, `;`, `,` | `C_DELIMITER` |
| Пробельные символы | ` `, `\t`, `\n` | `C_SPACE` |
| Конец файла | `⊥` | `C_TERMINATOR` |
| Другие | Все прочие символы | `C_OTHER` |

### 1.4. Обработка ошибок
В соответствии с требованиями к диагностике, лексический анализатор при переходе в состояние **S_ERROR** или некорректном завершении фиксирует:
1. Номер текущей строки.
2. Номер символа в строке, вызвавшего ошибку (позиция).


Лексические ошибки — это ситуации, когда автомат зашел в тупик и не может сформировать (закончить) ни одну валидную лексему на основе того что он проанализировал на данный момент. S_ERROR — мы нашли «мусор» или нарушили правила написания одной конкретной лексемы (числа, строки, комментария), и продолжать анализ этого куска текста невозможно.
